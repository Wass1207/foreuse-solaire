# Foreuse Solaire

Jeu idle de minage dans le système solaire, pensé pour le téléphone.

Fore les 6 étages de minerais de chaque planète, de Mercure à Éris, explore les lunes, bats les gardiens du noyau, puis fais des sauts stellaires vers des systèmes à l'infini.

**Jouer :** ouvre `index.html` dans un navigateur, ou la version en ligne via GitHub Pages.

La partie est sauvegardée dans le navigateur.

**Version de test à 100 % :** `complet.html` (sauvegarde séparée).
